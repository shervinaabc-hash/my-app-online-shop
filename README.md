# آفتاب انرژی | Solar Shop

A sample (portfolio) online store for a solar energy company, built with **Next.js 16**, **TypeScript** and **Tailwind CSS 4**.

## Features

- Product categories: solar panels, inverters and batteries
- Category bar under the navbar (filters the store with `?category=`)
- Search, pagination and product details page
- Shopping cart with discount codes (`OFF10`, `OFF20`, `OFF30`)
- Login with a cookie token and a protected admin panel (`src/proxy.ts`)

## Getting Started

```bash
npm install
npm run server   # fake API (json-server) on http://localhost:3002
npm run dev      # app on http://localhost:3000
```
